# Seedance 多上游下游接口路径对照表

本文档整理了 Seedance 视频生成和素材库接口在不同上游/下游的路径格式差异，方便查阅和对接。

---

## 一、多上游接口路径对照

### 1.1 视频生成接口

| 功能 | Gateway 上游 | KWJM 上游 | 说明 |
|------|-------------|-----------|------|
| **创建视频任务** | `POST /api/v3/contents/generations/tasks` | `POST /v1/videos/generations` | KWJM 使用简化路径 |
| **查询视频任务** | `GET /api/v3/contents/generations/tasks/{task_id}` | `GET /v1/videos/generations/{task_id}` | 路径格式不同 |
| **查询任务列表** | `GET /api/v3/contents/generations/tasks` | 不支持 | KWJM 不支持列表查询 |
| **删除视频任务** | `DELETE /api/v3/contents/generations/tasks/{task_id}` | 不支持 | KWJM 不支持删除 |

**请求格式差异**：
- **Gateway**: 标准 Doubao 官方 API 格式
- **KWJM**: 兼容 Doubao 官方 API 格式

**配置方式**：
```json
{
  "doubao_video_generate_path": "/v1/videos/generations",
  "doubao_video_fetch_path": "/v1/videos/generations"
}
```

### 1.2 素材库接口

#### Gateway 上游（RESTful 风格）

| 功能 | HTTP Method | 路径 | 说明 |
|------|------------|------|------|
| **创建素材组** | POST | `/api/seedance/proxy/assets/groups` | RESTful 风格 |
| **查询素材组** | GET | `/api/seedance/proxy/assets/groups/{id}` | 路径包含 ID |
| **更新素材组** | PUT/PATCH | `/api/seedance/proxy/assets/groups/{id}` | RESTful 风格 |
| **删除素材组** | DELETE | `/api/seedance/proxy/assets/groups/{id}` | RESTful 风格 |
| **查询素材组列表** | GET | `/api/seedance/proxy/assets/groups` | 无 ID |
| **创建素材** | POST | `/api/seedance/proxy/assets` | RESTful 风格 |
| **查询素材** | GET | `/api/seedance/proxy/assets/{id}` | 路径包含 ID |
| **更新素材** | PUT/PATCH | `/api/seedance/proxy/assets/{id}` | RESTful 风格 |
| **删除素材** | DELETE | `/api/seedance/proxy/assets/{id}` | RESTful 风格 |
| **查询素材列表** | GET | `/api/seedance/proxy/assets` | 无 ID |
| **创建真人认证会话** | POST | `/api/seedance/proxy/face-verifications` | RESTful 风格 |
| **查询真人认证结果** | GET | `/api/seedance/proxy/face-verifications/{id}` | RESTful 风格 |

**特点**：
- RESTful 风格，通过 HTTP Method + 路径组合表示操作
- 路径中包含资源 ID

---

#### KWJM 上游（Action 风格）

| 功能 | Action 名称 | 路径格式 | 说明 |
|------|-----------|---------|------|
| **创建素材组** | CreateAssetGroup | `POST {base_url}/v3/open/CreateAssetGroup` | Action 风格 |
| **查询素材组** | GetAssetGroup | `POST {base_url}/v3/open/GetAssetGroup` | 使用 POST + Body 传 ID |
| **更新素材组** | UpdateAssetGroup | `POST {base_url}/v3/open/UpdateAssetGroup` | 使用 POST |
| **删除素材组** | DeleteAssetGroup | `POST {base_url}/v3/open/DeleteAssetGroup` | 使用 POST |
| **查询素材组列表** | ListAssetGroups | `POST {base_url}/v3/open/ListAssetGroups` | 使用 POST + Body 过滤 |
| **创建素材** | CreateAsset | `POST {base_url}/v3/open/CreateAsset` | Action 风格 |
| **查询素材** | GetAsset | `POST {base_url}/v3/open/GetAsset` | 使用 POST + Body 传 ID |
| **更新素材** | UpdateAsset | `POST {base_url}/v3/open/UpdateAsset` | 使用 POST |
| **删除素材** | DeleteAsset | `POST {base_url}/v3/open/DeleteAsset` | 使用 POST |
| **查询素材列表** | ListAssets | `POST {base_url}/v3/open/ListAssets` | 使用 POST + Body 过滤 |
| **创建真人认证会话** | CreateVisualValidateSession | `POST {base_url}/v3/open/CreateVisualValidateSession` | Action 风格 |
| **查询真人认证结果** | GetVisualValidateResult | `POST {base_url}/v3/open/GetVisualValidateResult` | 使用 POST + Body 传 Token |

**特点**：
- Action 风格，所有操作都是 POST 请求
- 路径中包含 Action 名称
- 参数和 ID 都在请求 Body 中
- **所有请求必须包含 `model` 参数**

**请求体示例**：
```json
{
  "model": "sd-video-v2",
  "Name": "test-group",
  "GroupType": "AIGC",
  "Description": "test desc"
}
```

**配置方式**：
```json
{
  "asset_upstream_version": "kwjm",
  "kwjm_asset_base_url": "https://kwjm.com",
  "kwjm_asset_model": "sd-video-v2"
}
```

### 1.3 路径转换逻辑

系统内部使用统一的 RESTful 路径，根据上游配置自动转换：

| 内部路径（RESTful） | Gateway 上游 | KWJM 上游（Action） |
|--------------------|-------------|-------------------|
| `POST /api/seedance/proxy/assets/groups` | 直接使用 | → `CreateAssetGroup` |
| `GET /api/seedance/proxy/assets/groups/{id}` | 直接使用 | → `GetAssetGroup` |
| `PUT /api/seedance/proxy/assets/groups/{id}` | 直接使用 | → `UpdateAssetGroup` |
| `DELETE /api/seedance/proxy/assets/groups/{id}` | 直接使用 | → `DeleteAssetGroup` |
| `GET /api/seedance/proxy/assets/groups` | 直接使用 | → `ListAssetGroups` |
| `POST /api/seedance/proxy/assets` | 直接使用 | → `CreateAsset` |
| `GET /api/seedance/proxy/assets/{id}` | 直接使用 | → `GetAsset` |
| `PUT /api/seedance/proxy/assets/{id}` | 直接使用 | → `UpdateAsset` |
| `DELETE /api/seedance/proxy/assets/{id}` | 直接使用 | → `DeleteAsset` |
| `GET /api/seedance/proxy/assets` | 直接使用 | → `ListAssets` |
| `POST /api/seedance/proxy/face-verifications` | 直接使用 | → `CreateVisualValidateSession` |
| `GET /api/seedance/proxy/face-verifications/{id}` | 直接使用 | → `GetVisualValidateResult` |

**转换函数**：`service.pathToKwjmAction(path, method)` - 位于 `service/seedance_proxy.go`

## 二、多下游接口路径对照

### 2.1 视频生成接口（用户调用）

系统对外提供统一的下游接口，兼容多种客户端格式：

| 客户端格式 | 创建任务 | 查询任务 | 说明 |
|-----------|---------|---------|------|
| **Doubao 官方 API** | `POST /v1/video/generations` | `GET /v1/video/generations/{task_id}` | 推荐格式 |
| **OpenAI 兼容** | `POST /v1/videos` | `GET /v1/videos/{task_id}` | OpenAI 风格 |
| **Kling API** | `POST /kling/v1/videos/text2video` | `GET /kling/v1/videos/text2video/{task_id}` | Kling 专用 |
| **Doubao 原生** | `POST /api/v3/contents/generations/tasks` | `GET /api/v3/contents/generations/tasks/{task_id}` | Doubao 原生路径 |
| **Jimeng API** | `POST /jimeng` | - | 即梦专用 |

**路由配置**：位于 `router/video-router.go`

### 2.2 素材库接口（用户调用）

#### 方式1：统一 Action 风格（推荐）

**路径格式**：
```
POST /api/seedance/assets/v2/?Action={ActionName}&Version=2024-01-01
```

**支持的 Action**：

| Action 名称 | 功能 | 请求体参数 |
|------------|------|-----------|
| `CreateAssetGroup` | 创建素材组 | `Name`, `GroupType`, `Description`, `ProjectName` |
| `GetAssetGroup` | 查询素材组 | `Id`, `ProjectName` |
| `UpdateAssetGroup` | 更新素材组 | `Id`, `Name`, `Description`, `ProjectName` |
| `DeleteAssetGroup` | 删除素材组 | `Id`, `ProjectName` |
| `ListAssetGroups` | 查询素材组列表 | `Filter`, `PageNumber`, `PageSize`, `ProjectName` |
| `CreateAsset` | 创建素材 | `GroupId`, `URL`, `AssetType`, `Name`, `ProjectName` |
| `GetAsset` | 查询素材 | `Id`, `ProjectName` |
| `UpdateAsset` | 更新素材 | `Id`, `Name`, `ProjectName` |
| `DeleteAsset` | 删除素材 | `Id`, `ProjectName` |
| `ListAssets` | 查询素材列表 | `Filter`, `PageNumber`, `PageSize`, `ProjectName` |
| `CreateVisualValidateSession` | 创建真人认证 | `CallbackURL`, `ProjectName` |
| `GetVisualValidateResult` | 查询认证结果 | `BytedToken`, `ProjectName` |

**示例**：
```bash
curl -X POST \
  'http://your-api.com/api/seedance/assets/v2/?Action=CreateAsset&Version=2024-01-01' \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "GroupId": "group-xxx",
    "URL": "https://example.com/image.jpg",
    "AssetType": "Image",
    "Name": "test-image",
    "ProjectName": "default"
  }'
```

## 三、完整请求流程示例

### 3.1 使用 Gateway 上游

```
用户请求:
POST /api/seedance/assets/v2/?Action=CreateAsset

↓ 系统处理（controller/seedance.go）

内部调用:
service.AssetProxyRequest(gw, "POST", "/api/seedance/proxy/assets", nil, body)

↓ 检测到 upstream_version = "gateway"

上游请求:
POST https://gateway.com/api/seedance/proxy/assets

↓ 返回响应

用户收到结果
```

---

### 3.2 使用 KWJM 上游

```
用户请求:
POST /api/seedance/assets/v2/?Action=CreateAsset

↓ 系统处理（controller/seedance.go）

内部调用:
service.AssetProxyRequest(gw, "POST", "/api/seedance/proxy/assets", nil, body)

↓ 检测到 upstream_version = "kwjm"

路径转换:
pathToKwjmAction("/api/seedance/proxy/assets", "POST") → "CreateAsset"

↓ 添加 model 参数

上游请求:
POST https://kwjm.com/v3/open/CreateAsset
Body: { "model": "sd-video-v2", "GroupId": "...", "URL": "...", ... }

↓ 返回响应

用户收到结果
```

## 四、渠道配置参考

### 4.1 Gateway 渠道配置

```json
{
  "asset_upstream_version": "gateway",
  "seedance_asset_base_url": "https://gateway.com",
  "seedance_relay_mode": false
}
```

或者省略（默认为 gateway）：
```json
{}
```

---

### 4.2 KWJM 渠道配置

**完整配置**：
```json
{
  "asset_upstream_version": "kwjm",
  "kwjm_asset_base_url": "https://kwjm.com",
  "kwjm_asset_model": "sd-video-v2",
  "doubao_video_generate_path": "/v1/videos/generations",
  "doubao_video_fetch_path": "/v1/videos/generations"
}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `asset_upstream_version` | string | ✅ | 上游版本标识 | `kwjm` |
| `kwjm_asset_base_url` | string | ✅ | KWJM 资产库 Base URL | `https://kwjm.com` |
| `kwjm_asset_model` | string | ✅ | KWJM 默认模型 | `sd-video-v2` |
| `doubao_video_generate_path` | string | ✅ | 视频生成接口路径 | `/v1/videos/generations` |
| `doubao_video_fetch_path` | string | ✅ | 视频查询接口路径 | `/v1/videos/generations` |

## 七、常见问题

### Q1: 404 page not found 错误

**原因**：路径格式不匹配

**排查**：
1. 检查渠道配置中的 `asset_upstream_version`
2. 查看日志中的实际请求路径
3. 确认上游支持的路径格式

**解决**：
- Gateway 上游：`asset_upstream_version` 设为 `gateway` 或留空
- KWJM 上游：`asset_upstream_version` 设为 `kwjm`

---

### Q2: 资产找不到（AssetNotFound）

**原因**：资产在其他渠道创建，当前渠道找不到

**解决**：
- 确保资产创建和视频生成使用同一个渠道
- 或者实现跨渠道资产同步功能（开发中）

---

### Q3: model 参数缺失

**原因**：KWJM 上游要求所有请求都包含 `model` 参数

**解决**：
- 配置 `kwjm_asset_model` 字段
- 系统会自动注入该参数
