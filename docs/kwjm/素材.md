素材库 API
本页为素材库接口的通用说明（基于 kw-video-v2-fast 模型示例）。

素材库接口路径对所有支持的模型一致，仅调用的模型不同，因而不同模型对应的素材库能力（支持哪些接口、参数、返回字段）会有所差异。请根据你实际调用的模型，查看对应的差异说明文档：

模型	素材库能力特点	差异说明
kw-video-v2 / kw-video-v2-fast / kw-video-v2-mini / kw-video-v2.5	✅ 全部接口可用（本页通用）	—
we-video-v2 / we-video-v2-fast / we-video-v2-mini / we-video-v2.5	⚠️ 仅支持 CreateAsset / GetAsset / DeleteAsset，无素材组接口	we-video-v2 素材库差异
me-video-v2	⚠️ 仅支持 CreateAsset / GetAsset / DeleteAsset，无素材组接口	me-video-v2 素材库差异
sd-video-v2	✅ 全部接口可用，但部分参数/返回字段受限	sd-video-v2 素材库差异
下文中各接口的请求示例与响应字段，均以 kw-video-v2 / kw-video-v2-fast 为基准。若你调用的是上述差异模型，请以对应差异文档中的支持情况为准。

1. 创建素材组合
接口: POST {base_url}/v3/open/CreateAssetGroup

功能说明: 创建一个新的素材组合，用于管理相关素材。

请求示例:


curl -X POST {base_url}/v3/open/CreateAssetGroup \
    -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"kw-video-v2-fast",
    "Name" : "test-group",
    "GroupType": "AIGC",
    "Description": "test desc"
  }'
请求参数:

参数	类型	必填	说明	示例/取值
model	string	✅	模型名称	kw-video-v2-fast
Name	string	✅	素材组合名称 ,32个字符以内	test-group
GroupType	string	✅	素材组合类型	AIGC
Description	string	❌	素材组合描述	test desc
成功响应:


{
  "Id": "group-xxx-jndf5"
}
响应字段说明:

字段	类型	说明
Id	string	素材组合唯一标识

3. 查询素材组合列表
接口: POST {base_url}/v3/open/ListAssetGroups

功能说明: 查询符合条件的素材组合列表，支持分页和排序。

请求示例:


curl -X POST {base_url}/v3/open/ListAssetGroups \
    -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"kw-video-v2-fast",
    "Filter":{
        "GroupType": "AIGC"
     },
    "PageNumber" : 1,
    "PageSize": 100,
    "SortBy": "CreateTime",
    "SortOrder": "Desc"
  }'
请求参数:

参数	类型	必填	说明	示例/取值
model	string	✅	模型名称	kw-video-v2-fast
Filter	object	✅	过滤条件	-
Filter.GroupType	string	✅	按素材组合类型过滤	AIGC
PageNumber	int	✅	页码	1
PageSize	int	✅	每页数量	100
SortBy	string	❌	排序字段	CreateTime, UpdateTime, GroupId
SortOrder	string	❌	排序方向	Asc, Desc
成功响应:


{
  "TotalCount": 100,
  "PageNumber": 1,
  "PageSize": 100,
  "Items": [
    {
      "Id": "group-xxxx-jndf5",
      "Name": "test-group",
      "GroupType": "AIGC",
      "createTime": "2026-03-28T19:39:29Z",
      "updateTime": "2026-03-28T19:39:29Z"
    }
  ]
}
响应字段说明:

字段	类型	说明
TotalCount	int	总记录数
PageNumber	int	当前页码
PageSize	int	每页数量
Items	array	素材组合列表
Items.Id	string	素材组合ID
Items.Name	string	素材组合名称
Items.GroupType	string	素材组合类型
Items.createTime	string	创建时间 (ISO 8601 格式)
Items.updateTime	string	更新时间 (ISO 8601 格式)

错误码说明:

当 Status = Failed 时，可通过 Error.Code/Error.Message 获取失败原因：

错误码	错误原因
FaceMismatch	真人脸一致性校验失败，素材中的人脸与参考/授权人脸不一致
TranscodingFailed	媒体转码或处理失败
ContentRestricted	内容安全审核未通过
DownloadFailed	无法下载客户提供的素材URL
TypeMismatch	上传素材类型与声明类型不一致，例如声明视频但实际是图片
FormatUnsupported	素材格式不支持
FormatUndetectable	无法识别素材格式，可能文件损坏或格式异常
AudioTrackRequired	要求必须包含音轨，但素材中未检测到音轨
AudioTrackForbidden	要求不能包含音轨，但素材中检测到音轨
DurationTooShort	素材时长低于业务要求
DurationTooLong	素材时长超过业务限制
WidthTooSmall / HeightTooSmall	素材宽度或高度低于要求
WidthTooLarge / HeightTooLarge	素材宽度或高度超过限制
AspectRatioTooSmall / AspectRatioTooLarge	素材宽高比不符合要求
FileSizeTooLarge	素材文件大小超过限制
PixelCountTooSmall / PixelCountTooLarge	素材总像素数不符合要求
FpsTooLow / FpsTooHigh	视频帧率不符合要求
InputTextSensitiveContentDetected	文本内容安全审核未通过
InputImageSensitiveContentDetected	图片内容安全审核未通过
InputVideoSensitiveContentDetected	视频内容安全审核未通过
InputAudioSensitiveContentDetected	音频内容安全审核未通过
InputTextSensitiveContentDetected.PolicyViolation	文本涉及版权/政策限制
InputImageSensitiveContentDetected.PolicyViolation	图片涉及版权/政策限制
InputVideoSensitiveContentDetected.PolicyViolation	视频涉及版权/政策限制
InputAudioSensitiveContentDetected.PolicyViolation	音频涉及版权/政策限制
ModerationServiceErrorUploadFailed	审核服务暂不可用或审核上传失败，建议重新上传
InternalError	素材处理过程中出现内部异常
接口错误码:

错误码	错误原因
MissingParameter.AssetID	未传入资产ID
InvalidParameter.AssetID	资产ID格式不正确
NotFound.asset_id	资产不存在，或当前账号/项目无权访问该资产
SubscriptionRequired	当前套餐不支持读取该类资产能力，例如AIGC资产能力不可用
InternalError	服务内部异常，建议稍后重试或联系支持
