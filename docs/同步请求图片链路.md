设计就是同步等待。完整链路：

  客户端 → 咱们网关 → 上游网关 → OpenAI → 原路返回

  全程同步阻塞，没有异步/回调机制。

  超时处理：

  - RELAY_TIMEOUT 环境变量控制网关到上游的 HTTP 超时（默认 0 = 不超时，无限等待）
  - 如果配置了超时值，超时后 HTTP client 断开连接，返回 context deadline exceeded 错误给客户端
  - 如果不配置，就一直等，直到上游返回或连接被强制断开

  gpt-image-2 生图一般需要 30~60 秒，如果客户端自身有超时（比如浏览器、移动端默认 30s），可能在上游还没返回时就断开了，但网关侧的请求还在挂着。

  建议生产环境设置 RELAY_TIMEOUT=180（3分钟），给图片生成留足时间。
