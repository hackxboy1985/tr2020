## 功能特性

### 表单模式

#### 条件映射规则（V2）
- 添加/删除规则
- 配置源模型和目标模型
- 添加多个条件（AND逻辑）
- 支持的参数：
  - temperature - 温度
  - max_tokens - 最大Token
  - max_completion_tokens - 最大完成Token
  - top_p - Top-P采样
  - top_k - Top-K采样
  - stream - 流式输出
  - frequency_penalty - 频率惩罚
  - presence_penalty - 存在惩罚
  - n - 生成数量
  - reasoning_effort - 推理强度
- 支持的运算符：
  - `>` 大于
  - `>=` 大于等于
  - `<` 小于
  - `<=` 小于等于
  - `==` 等于
  - `!=` 不等于
  - `in` 在数组中
  - `not_in` 不在数组中
- 设置优先级和描述

#### 简单映射（V1兼容）
- 添加/删除映射对
- 源模型 → 目标模型
- 用于旧版本服务器兼容

### JSON模式
- 直接编辑JSON配置
- 实时语法验证
- 支持复制粘贴

## 使用示例

### 示例1：基于温度的条件映射

**表单配置**：
- 条件规则：
  - 源模型：gpt-4
  - 目标模型：gpt-4-turbo
  - 条件：temperature > 0.8
- V1兼容：
  - gpt-4 → gpt-4o

**生成的JSON**：
```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "target_model": "gpt-4-turbo",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.8}
      ]
    }
  ],
  "gpt-4": "gpt-4o"
}
```

**效果**：
- 新服务器：temperature > 0.8 → gpt-4-turbo，否则 → gpt-4o
- 旧服务器：gpt-4 → gpt-4o

### 示例2：多条件映射

**表单配置**：
- 条件规则：
  - 源模型：gpt-4
  - 目标模型：gpt-4-32k
  - 条件1：temperature > 0.7
  - 条件2：max_tokens >= 4000
  - 优先级：1
- V1兼容：
  - gpt-4 → gpt-4-8k

**生成的JSON**：
```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "target_model": "gpt-4-32k",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.7},
        {"param": "max_tokens", "operator": ">=", "value": 4000}
      ],
      "priority": 1
    }
  ],
  "gpt-4": "gpt-4-8k"
}
```

## 技术实现

### 优先级逻辑

后端处理优先级：
```
V2规则（有条件） > V1兼容字段（无条件）
```

### V1兼容原理

生成的配置同时包含：
1. V2字段：`version: 2`, `rules: [...]`
2. V1字段：顶层的字符串键值对

**新服务器**：
- 识别 `version: 2`
- 优先匹配 `rules`
- 规则不匹配时使用顶层V1字段

**旧服务器**：
- 尝试解析为 `map[string]string`
- 只提取顶层字符串字段（V1格式）
- 忽略 `version`, `rules` 等复杂类型字段

### 数据流

```
用户编辑表单
  ↓
生成JSON配置 (generateConfig)
  ↓
保存到表单字段 (onChange)
  ↓
提交到后端
  ↓
存储到数据库
```
