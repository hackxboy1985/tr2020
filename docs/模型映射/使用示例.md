# 模型映射 V2 - 使用示例

## 配置示例

### 示例1：根据温度参数映射

```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.8}
      ],
      "target_model": "gpt-4-turbo",
      "priority": 1,
      "description": "高创造性任务使用 turbo"
    }
  ],
  "fallback": {
    "gpt-4": "gpt-4o"
  }
}
```

**效果**：
- 请求 `gpt-4` + `temperature=0.9` → 映射到 `gpt-4-turbo`
- 请求 `gpt-4` + `temperature=0.5` → 映射到 `gpt-4o`（fallback）
- 请求 `gpt-4` + 无temperature → 映射到 `gpt-4o`（fallback）

### 示例2：根据多个条件映射

```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.7},
        {"param": "max_tokens", "operator": ">=", "value": 4000}
      ],
      "target_model": "gpt-4-32k",
      "description": "高温度+长输出使用32k模型"
    },
    {
      "source_model": "gpt-4",
      "conditions": [
        {"param": "stream", "operator": "==", "value": false}
      ],
      "target_model": "gpt-4-instruct",
      "description": "非流式使用instruct"
    }
  ],
  "fallback": {
    "gpt-4": "gpt-4-8k"
  }
}
```

**效果**：
- 请求 `gpt-4` + `temperature=0.8, max_tokens=5000` → `gpt-4-32k`
- 请求 `gpt-4` + `stream=false` → `gpt-4-instruct`
- 请求 `gpt-4` + 其他参数 → `gpt-4-8k`

### 示例3：优先级控制

```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.9}
      ],
      "target_model": "gpt-4-turbo-ultra",
      "priority": 1,
      "description": "极高温度优先匹配"
    },
    {
      "source_model": "gpt-4",
      "conditions": [
        {"param": "temperature", "operator": ">", "value": 0.5}
      ],
      "target_model": "gpt-4-turbo",
      "priority": 2,
      "description": "中高温度次优先"
    }
  ]
}
```

**效果**：
- 请求 `gpt-4` + `temperature=0.95` → `gpt-4-turbo-ultra`（优先级1）
- 请求 `gpt-4` + `temperature=0.7` → `gpt-4-turbo`（优先级2）

### 示例4：无条件映射（等价于V1）

```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "target_model": "gpt-4-turbo"
    },
    {
      "source_model": "claude-3",
      "target_model": "claude-3-sonnet"
    }
  ]
}
```

等价于V1配置：
```json
{
  "gpt-4": "gpt-4-turbo",
  "claude-3": "claude-3-sonnet"
}
```

## 支持的运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `>` | 大于 | `{"param": "temperature", "operator": ">", "value": 0.8}` |
| `>=` | 大于等于 | `{"param": "max_tokens", "operator": ">=", "value": 4000}` |
| `<` | 小于 | `{"param": "temperature", "operator": "<", "value": 0.3}` |
| `<=` | 小于等于 | `{"param": "top_p", "operator": "<=", "value": 0.5}` |
| `==` | 等于 | `{"param": "stream", "operator": "==", "value": false}` |
| `!=` | 不等于 | `{"param": "model", "operator": "!=", "value": "gpt-3.5"}` |
| `in` | 值在数组中 | `{"param": "reasoning_effort", "operator": "in", "value": ["low", "medium"]}` |
| `not_in` | 值不在数组中 | `{"param": "model", "operator": "not_in", "value": ["gpt-3.5"]}` |

## 支持的参数

### 一级参数（直接访问，性能最优）

- `temperature` - 温度参数
- `max_tokens` - 最大输出token数
- `max_completion_tokens` - 最大完成token数
- `top_p` - Top-P采样
- `top_k` - Top-K采样
- `stream` - 是否流式输出
- `frequency_penalty` - 频率惩罚
- `presence_penalty` - 存在惩罚
- `n` - 生成数量
- `reasoning_effort` - 推理强度
- `model` - 模型名

### 嵌套参数（需要JSON解析）

对于嵌套字段，使用点号分隔：
- `response_format.type` - 响应格式类型
- `stream_options.include_usage` - 流式选项
- `extra_body.generationConfig.temperature` - 额外参数

## 测试配置

可以使用以下请求测试配置：

```bash
# 测试高温度映射
curl -X POST http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4",
    "temperature": 0.9,
    "messages": [{"role": "user", "content": "Hello"}]
  }'

# 测试低温度映射
curl -X POST http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4",
    "temperature": 0.3,
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

## 日志示例

配置成功时的日志：
```
[INFO] 模型映射V2: 规则[0]匹配成功 gpt-4 -> gpt-4-turbo (优先级=1, 描述=高创造性任务使用 turbo)
```

条件不匹配时的日志：
```
[DEBUG] 模型映射V2: 规则[0]条件不匹配 [temperature > 0.8]: 0.5 不满足 > 0.8
[INFO] 模型映射V2: 使用fallback gpt-4 -> gpt-4o
```

## 迁移指南

### 从V1迁移到V2

**V1配置**：
```json
{
  "gpt-4": "gpt-4-turbo"
}
```

**等价的V2配置**：
```json
{
  "version": 2,
  "rules": [
    {
      "source_model": "gpt-4",
      "target_model": "gpt-4-turbo"
    }
  ]
}
```

或使用fallback（更简洁）：
```json
{
  "version": 2,
  "rules": [],
  "fallback": {
    "gpt-4": "gpt-4-turbo"
  }
}
```

## 注意事项

1. **参数不存在时**：条件自动失败，不会匹配该规则
2. **所有条件必须满足**：多个条件之间是AND关系
3. **优先级规则**：数值越小优先级越高，相同优先级按定义顺序
4. **不支持链式映射**：V2映射一次后立即返回
5. **向后兼容**：V1配置继续正常工作
