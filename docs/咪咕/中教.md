## 1. 客户交付信息

| --- | --- |
| 登录地址 | `https://sd.dawnloadai.com:8443/login` |
| 客户账号 | `<zj20260710>` |

| 已分配分组 | `<default / vip90 / vip85 / vip80 / vip75 / vip70>` |
| 分组折扣 | `<由交付方填写>` |

> 请在首次登录后修改初始密码，并妥善保管账号、密码和 API Token。

## 2. 登录 NewAPI 后台

当前后台使用 NewAPI 新版前端。本文档中的菜单名称和操作路径均以新版界面为准；如果浏览器仍显示旧版界面或旧 Logo，请清理站点缓存后强制刷新。

1. 在浏览器打开 `https://sd.dawnloadai.com:8443/login`。
2. 在“用户名”中输入交付的客户账号。
3. 在“密码”中输入交付的初始密码。
4. 点击“登录”进入控制台。
5. 首次登录后，请在个人设置中修改密码。

如果提示账号、密码错误或账号被禁用，请联系交付方，不要多次连续尝试。

## 3. 创建 API Token

### 3.1 进入令牌管理

1. 登录后，在左侧导航栏打开“令牌管理”。
2. 点击“添加令牌”。
3. 系统会打开“创建新的令牌”页面。

也可在登录后直接访问：

```text
https://sd.dawnloadai.com:8443/console/token
```

### 3.2 填写令牌信息

| 字段 | 建议设置 | 说明 |
| --- | --- | --- |
| 名称 | 例如 `seedance-production` | 用于区分不同应用或环境 |
| 令牌分组 | 选择交付方分配的分组 | 分组决定实际计费折扣 |
| 过期时间 | 按项目周期设置 | 可选永不过期、一个月、一天或自定义时间 |
| 新建数量 | `1` | 每个应用建议使用单独 Token |
| 无限额度 | 按交付要求选择 | 开启后仍受客户账户总额度限制 |
| 模型限制 | 可选 | 如开启，请包含 `doubao-seedance-2-0-260128` |
| IP 白名单 | 建议生产环境填写 | 只允许指定公网 IP 或 CIDR 调用 |

分组与折扣对照：

| 分组 | 计费折扣 |
| --- | ---: |
| `default` | 原价 |
| `vip90` | 9 折 |
| `vip85` | 8.5 折 |
| `vip80` | 8 折 |
| `vip75` | 7.5 折 |
| `vip70` | 7 折 |

> 客户应选择“已分配分组”中的分组。如果下拉列表中没有对应分组，请联系交付方，不要选择其他分组。

### 3.3 提交并复制 Token

1. 点击“提交”。
2. 返回“令牌创建成功”后，回到令牌列表。
3. 找到刚创建的令牌，点击复制按钮获取完整 Token。
4. Token 格式如下：

```text
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

5. 将该 Token 保存到应用的服务端密钥配置或安全的密钥管理系统中。

该 Token 同时用于 NewAPI 视频生成接口和 Seedance Gateway 素材库/人像库接口。不要将 Token 写入前端源码、公开 Git 仓库、截图或聊天记录。

## 4. 服务地址

| 服务 | Base URL | 用途 |
| --- | --- | --- |
| NewAPI | `https://sd.dawnloadai.com:8443` | Seedance 2.0 视频生成和任务查询 |
| Seedance Gateway | `https://sd.dawnloadai.com:9444` | 素材库和真人人像库 |

两个服务使用同一枚 NewAPI Token。

## 5. 统一鉴权

所有业务请求都需要携带：

```http
Authorization: Bearer sk-<API_TOKEN>
Content-Type: application/json
```

Token 状态、有效期、额度和用户分组由 NewAPI 统一管理。素材库和人像库请求不扣减视频生成额度。

## 6. NewAPI 视频生成

### 6.1 查询可用模型

```http
GET /v1/models
```

```bash
curl 'https://sd.dawnloadai.com:8443/v1/models' \
  -H 'Authorization: Bearer sk-<API_TOKEN>'
```

Seedance 2.0 模型名：

```text
doubao-seedance-2-0-260128
```

### 6.2 创建视频任务

```http
POST /v1/video/generations
```

文生视频示例：

```bash
curl -X POST \
  'https://sd.dawnloadai.com:8443/v1/video/generations' \
  -H 'Authorization: Bearer sk-<API_TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "prompt": "清晨的湖面上薄雾缓缓流动，固定镜头，真实摄影风格",
    "seconds": "5",
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": false,
      "watermark": false
    }
  }'
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定使用 `doubao-seedance-2-0-260128` |
| `prompt` | string | 是 | 视频提示词 |
| `seconds` | string | 否 | 视频时长，例如 `"5"` |
| `images` | string[] | 否 | 参考图 URL 或 `asset://<asset_id>` |
| `metadata.resolution` | string | 否 | 分辨率，例如 `480p`、`720p`、`1080p` |
| `metadata.ratio` | string | 否 | 画面比例，例如 `16:9`、`9:16`、`1:1` |
| `metadata.generate_audio` | boolean | 否 | 是否生成音频 |
| `metadata.watermark` | boolean | 否 | 是否生成水印 |
| `metadata.seed` | integer | 否 | 随机种子 |
| `metadata.camera_fixed` | boolean | 否 | 是否固定摄像机 |

图生视频示例：

```json
{
  "model": "doubao-seedance-2-0-260128",
  "prompt": "人物自然转头看向镜头，真实摄影风格",
  "seconds": "5",
  "images": [
    "https://example.com/reference.jpg"
  ],
  "metadata": {
    "resolution": "720p",
    "ratio": "16:9"
  }
}
```

使用素材库图片：

```json
{
  "model": "doubao-seedance-2-0-260128",
  "prompt": "参考图中的人物在街道上自然行走",
  "seconds": "5",
  "images": [
    "asset://asset-xxxxxxxx"
  ],
  "metadata": {
    "resolution": "720p",
    "ratio": "16:9"
  }
}
```

创建成功响应：

```json
{
  "id": "task_xxxxxxxxxxxxxxxx",
  "task_id": "task_xxxxxxxxxxxxxxxx",
  "object": "video",
  "model": "doubao-seedance-2-0-260128",
  "status": "queued",
  "progress": 0,
  "created_at": 1783693498
}
```

请保存 `id`，后续使用该 ID 查询任务。

### 6.3 查询视频任务

```http
GET /v1/videos/{task_id}
```

```bash
curl \
  'https://sd.dawnloadai.com:8443/v1/videos/task_xxxxxxxxxxxxxxxx' \
  -H 'Authorization: Bearer sk-<API_TOKEN>'
```

任务状态：

| 状态 | 说明 |
| --- | --- |
| `queued` | 已进入队列 |
| `in_progress` | 生成中 |
| `completed` | 生成成功 |
| `failed` | 生成失败 |

生成成功后，视频地址会出现在响应的 `metadata.url` 或结果 URL 字段中。

## 7. Seedance Gateway 素材库

Gateway 不提供视频生成和视频任务查询。请求体中不需要传递任何项目或上游鉴权信息。

### 7.1 创建素材组

```http
POST /api/seedance/proxy/assets/groups
```

```bash
curl -X POST \
  'https://sd.dawnloadai.com:9444/api/seedance/proxy/assets/groups' \
  -H 'Authorization: Bearer sk-<API_TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "Name": "brand-assets",
    "Description": "品牌素材组",
    "GroupType": "AIGC"
  }'
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Name` | string | 是 | 素材组名称 |
| `Description` | string | 否 | 素材组描述 |
| `GroupType` | string | 是 | 普通 AIGC 素材固定使用 `AIGC` |

成功响应中的 `Result.Id` 是素材组 ID。

### 7.2 查询素材组列表

```http
GET /api/seedance/proxy/assets/groups?PageNumber=1&PageSize=20
```

默认查询 `AIGC` 素材组。查询真人素材组时增加 `GroupType=LivenessFace`。

### 7.3 查询、修改或删除素材组

```http
GET /api/seedance/proxy/assets/groups/{group_id}
PUT /api/seedance/proxy/assets/groups/{group_id}
PATCH /api/seedance/proxy/assets/groups/{group_id}
DELETE /api/seedance/proxy/assets/groups/{group_id}
```

### 7.4 创建素材

```http
POST /api/seedance/proxy/assets
```

```bash
curl -X POST \
  'https://sd.dawnloadai.com:9444/api/seedance/proxy/assets' \
  -H 'Authorization: Bearer sk-<API_TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "GroupId": "group-xxxxxxxx",
    "URL": "https://example.com/reference.jpg",
    "AssetType": "Image",
    "Name": "reference-image"
  }'
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `GroupId` | string | 是 | 所属素材组 ID |
| `URL` | string | 是 | 上游可访问的公网 HTTPS 文件地址 |
| `AssetType` | string | 是 | `Image`、`Video` 或 `Audio` |
| `Name` | string | 否 | 素材名称 |

成功响应中的 `Result.Id` 是素材 ID。创建成功只表示已提交预处理，需继续查询状态。

### 7.5 查询素材列表

```http
GET /api/seedance/proxy/assets?PageNumber=1&PageSize=20
```

默认查询 `AIGC` 素材。查询真人素材时增加 `GroupType=LivenessFace`。

### 7.6 查询素材状态

```http
GET /api/seedance/proxy/assets/{asset_id}
```

```bash
curl \
  'https://sd.dawnloadai.com:9444/api/seedance/proxy/assets/asset-xxxxxxxx' \
  -H 'Authorization: Bearer sk-<API_TOKEN>'
```

常见素材状态：

| 状态 | 说明 |
| --- | --- |
| `Processing` | 预处理中 |
| `Active` | 已可用，可以通过 `asset://<asset_id>` 用于视频生成 |
| `Failed` | 预处理失败 |

### 7.7 修改或删除素材

```http
PUT /api/seedance/proxy/assets/{asset_id}
PATCH /api/seedance/proxy/assets/{asset_id}
DELETE /api/seedance/proxy/assets/{asset_id}
```

## 8. Seedance Gateway 真人人像库

Gateway 使用有状态认证工作流。调用方不接触 `BytedToken`，也不能在 H5 认证完成前查询上游结果。

人脸认证、真人素材和普通素材均使用登录 NewAPI 后创建的同一个 API Key。Gateway 会根据 API Key 所属用户自动选择对应项目；调用方不传递 `ProjectName`、AccessKey ID 或 Secret Access Key。不同用户的认证任务和素材项目相互隔离。

### 8.1 创建真人认证任务

```http
POST /api/seedance/face-verifications
```

```bash
curl -X POST \
  'https://sd.dawnloadai.com:9444/api/seedance/face-verifications' \
  -H 'Authorization: Bearer sk-<API_TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "return_url": "https://customer.example.com/face-result"
  }'
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `return_url` | string | 否 | Gateway 处理完 H5 回调后的客户页面跳转地址 |

成功响应：

```json
{
  "verification_id": "fv_xxxxxxxxx",
  "status": "waiting_user",
  "h5_url": "https://...",
  "expires_at": 1783740000
}
```

调用方只需保存 `verification_id`，并让终端用户打开 `h5_url` 完成真人认证。

### 8.2 查询认证任务

```http
GET /api/seedance/face-verifications/{verification_id}
```

```bash
curl \
  'https://sd.dawnloadai.com:9444/api/seedance/face-verifications/fv_xxxxxxxxx' \
  -H 'Authorization: Bearer sk-<API_TOKEN>'
```

状态值：

| 状态 | 说明 |
| --- | --- |
| `waiting_user` | 等待用户在 H5 完成认证 |
| `callback_received` | Gateway 已收到 H5 成功回调 |
| `resolving` | Gateway 正在向上游获取 `GroupId` |
| `verified` | 认证成功 |
| `failed` | 认证失败 |
| `expired` | 认证任务已过期 |

认证成功响应：

```json
{
  "verification_id": "fv_xxxxxxxxx",
  "status": "verified",
  "group_id": "group-xxxxxxxx",
  "expires_at": 1783740000
}
```

获得 `group_id` 后，使用素材创建接口向该人像组添加本人图片、视频或音频。

完整的可执行 `curl + jq` 示例见 [人脸认证与真人素材调用 Demo](./FACE-ASSET-DEMO.zh-CN.md)，包括创建认证、打开 H5、轮询认证结果、创建真人素材和等待素材可用。

## 9. 完整调用流程

### 普通素材

1. Gateway 创建 `AIGC` 素材组。
2. Gateway 使用公网 HTTPS URL 创建素材。
3. Gateway 轮询素材，直到状态变为 `Active`。
4. NewAPI 创建视频，参考图填写 `asset://<asset_id>`。
5. NewAPI 轮询视频任务，直到成功或失败。

### 真人人像

1. 调用方创建 Gateway 真人认证任务，保存 `verification_id`。
2. 让终端用户打开 `h5_url` 并完成认证。
3. 调用方查询认证任务，等待状态变为 `verified`并获得 `group_id`。
4. Gateway 向该 `group_id` 创建本人素材。
5. Gateway 轮询素材，直到状态变为 `Active`。
6. NewAPI 使用 `asset://<asset_id>` 创建视频。

## 10. 错误处理

### NewAPI 常见错误

| HTTP 状态码 | 说明 |
| --- | --- |
| `400` | 请求字段或模型参数错误 |
| `401` | Token 缺失或无效 |
| `403` | Token 额度不足、用户被禁用或没有模型权限 |
| `429` | 请求过于频繁 |
| `500` / `502` | NewAPI 或上游服务异常 |

### Gateway 常见错误

| HTTP 状态码 | 错误码 | 说明 |
| --- | --- | --- |
| `400` | `invalid_json` | JSON 请求体格式错误 |
| `401` | `unauthorized` | Token 缺失、无效或对应用户不可用 |
| `404` | `unsupported_seedance_route` | 请求路径不在素材库/人像库白名单中 |
| `413` | `request_body_too_large` | 请求体超过限制 |
| `502` | `upstream_request_failed` | 上游请求失败 |
| `503` | `auth_backend_unavailable` | NewAPI 鉴权暂时不可用 |
| `503` | `user_upstream_not_configured` | 当前 Token 所属用户尚未配置人脸与素材项目 |
| `504` | `upstream_timeout` | 上游请求超时 |

Gateway 会保留上游业务错误的 HTTP 状态码和错误内容，但不会返回服务器内部的项目信息或上游鉴权凭据。
